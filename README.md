# Manage Campaign End Date Extensions

This example demonstrates how to manage and extend campaign end dates, a core technical concept from the article. It simulates adding campaigns, checking their active status, and dynamically updating their expiration dates using Python's `datetime` module. It shows how an expired campaign can be reactivated by extending its duration.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
